How accurate is it?

We measured the published results ourselves, from the pixels each preview changed. The samples are small and come from one provider version each; they identify differences worth reviewing, without establishing overall fidelity.

  • Clothes colour: {{ s.clothes.close }} of {{ s.clothes.plain }} plain tops are within ΔE {{ accuracy.thresholds.close_garment_delta|floatformat:0 }} of the product's reviewed colour (ΔE {{ s.clothes.range.0 }} to {{ s.clothes.range.1 }}). The {{ s.clothes.patterned }} patterned tops are not measured.
  • Beauty shades: {{ s.shades.small }} of {{ s.shades.readable }} readable results are within ΔE {{ accuracy.thresholds.small_shade_delta|floatformat:0 }} of the requested shade (ΔE {{ s.shades.range.0 }} to {{ s.shades.range.1 }}){% if accuracy.unreadable_shades %}; {{ accuracy.unreadable_shades }} changed too little to measure{% endif %}.
  • Earring size: {{ s.earrings.in_proportion }} of {{ s.earrings.compared }} earrings render in proportion to their catalog length, compared with the pair bought.{% for e in accuracy.off_proportion %} The {{ e.length_mm }} mm {{ e.title }} renders {{ e.difference_abs }}% {{ e.status }} than its length implies.{% endfor %} The size sent to YouCam does not control drop length, so Rechoice resizes an earring that renders out of proportion, from where it hangs, and measures it again: resized, {{ s.earrings.in_proportion_resized }} of {{ s.earrings.compared }} are in proportion. The shopper is told, and can see it as YouCam drew it.

ΔE is the CIEDE2000 colour difference: about 2 is just noticeable, under 5 is small and over 10 is clearly different. Colours are re-measured from the stored results, which the app saves as JPEG; for shades this differs from the live check, made on YouCam's original file, by up to ΔE {{ s.shades.largest_gap_to_live }}, which is the measurement's own noise. Earring proportions are compared with the pair bought because the photo has no ruler. The correction uses catalog length ratios; it does not establish physical length or fit on a person.
